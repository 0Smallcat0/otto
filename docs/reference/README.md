# Reference material — kept private

Otto was built clean-room by **observing** a reference terminal's workflow and shape,
never by reading or copying its code. In the private working repository this directory
holds those raw observation notes (feature/menu/function inventories, UI-flow captures,
and platform research).

That corpus is **intentionally excluded from the public repository** to preserve the
clean-room boundary: publishing detailed third-party observations would undermine the
separation the source wall exists to enforce. Links to files under
`docs/reference/fincept-platform-test/` elsewhere in the planning ledger therefore point
into this intentionally-unpublished material.

The enforced boundary itself is public and testable: see `AGENTS.md` and
`tests/test_clean_room_source_wall.py`.
